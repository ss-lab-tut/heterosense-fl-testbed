# 先生への進捗報告案：構造的遮蔽モデル

条件推定研究の前提を検証するため、従来のランダム点欠落と、壁・家具による構造的遮蔽を分けて実験しました。

従来方式では、遮蔽率に応じて各点を独立に削除していました。この条件はpoint countから直接推定でき、全特徴で遮蔽推定が `1.000 ± 0.000` になりました。しかしpoint countとその比率を除くと `0.515 ± 0.026` まで低下しました。このため、従来方式だけでP1の有効性を主張すると、シミュレータ内部の単純な生成規則を読み取っているだけになると判断しました。

そこで、LiDARから点への視線と壁・家具の矩形領域との交差を判定し、遮蔽物の背後に連続した影を作る構造的遮蔽を追加しました。新しい処理は乱数を使用せず、設定しない限り無効です。実装前後の既定出力を直接比較したSHA-256も完全一致しています。

構造的遮蔽では、学習に含めない壁・家具配置とseedを同時にheld-outにして5回評価しました。結果は次の通りです。

- 全観測特徴: balanced accuracy `0.753 ± 0.202`
- point countを除外: `0.735 ± 0.205`
- LiDAR形状特徴のみ: `0.729 ± 0.198`
- 全特徴での遮蔽recall: `0.673 ± 0.383`
- 全特徴でのfalse-positive rate: `0.168 ± 0.027`

ランダム欠落とは異なり、point countを除いても偶然水準より高いため、構造的な影はz分布や空間的広がりにも現れています。ただし条件差が大きく、大きな壁ではbalanced accuracyが0.85〜0.92だった一方、中央の低い家具では0.443、遮蔽recallは0.101でした。

現時点の結論は、「観測統計から壁遮蔽を推定できる場合はあるが、単一frameの全体統計だけでは局所的な家具遮蔽へ一般化しない」です。良い平均値だけを主張せず、この失敗条件を次の研究対象にします。

次は、観測可能な入力だけを使う制約を維持したまま、次を検討します。

1. calibration baselineに対する方位sector別の点数・z統計を追加する。
2. 単一frameではなく短い時間windowから条件を推定する。
3. 未知の家具位置・壁位置で再評価する。
4. 条件推定が改善した場合にのみ、P1の動的閾値へ接続する。

すべてシミュレーション上の暫定結果です。特に天井視点については、実LiDAR点群で検証するまで結論に使いません。
